# シューティングゲーム 🚀

ブラウザで遊べるシンプルなシューティングゲームです。

## 🎮 遊び方（リンク）

**▶ [ここをクリックしてゲームを起動](https://seijisa.github.io/shootinggame/)**

## 操作方法

| キー | 動作 |
|------|------|
| `←` / `→` または `A` / `D` | 左右移動 |
| `スペース` | 射撃 |
| `Enter` | スタート / 再スタート |

## ゲームのルール

- 敵機を撃ち落とすと **+100点**
- 敵機を見逃すか体当たりされると **残機が1減る**
- 残機が 0 になるとゲームオーバー
- **500点ごとにレベルアップ**し、敵が速く・多くなる
